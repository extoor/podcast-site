# textplayer

[English](README.md) | **Русский**

Аудиоплеер в текстовом стиле DOS для обычных ссылок на аудиофайлы. Окно появляется
по центру поверх страницы и целиком нарисовано символами: рамки `╔═╗`, полосы `█░`.
Один файл без зависимостей, стили он подключает сам.

```
╔═══════════════════════ Browser Player v0.3.0 ════════════════════════╗
║ File:    mordax-bastards-zebra-2015-04-04-podkasty-04.04.15-kissfm.… ║
╟──────────────────────────────────────────────────────────────────────╢
║ Title:   ZEBRA                                                       ║
║ Artist:  MORDAX Bastards                                             ║
║ Podcast: Zebra                                                       ║
║ Date:    04.04.2015    Track: 1/25      Size: 86 MB                  ║
╟──────────────────────────────────────────────────────────────────────╢
║ Codec:   MPEG-1 Layer III  192 kbps CBR  44.1 kHz  Stereo            ║
║ Decoder: Chrome   Buf: █████████████ 02:19  Vol: █████████████   0dB ║
╟──────────────────────────────────────────────────────────────────────╢
║ ► 00:02 ░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░░ 59:59 ║
```

## Подключение

```html
<ol>
  <li><a href="/media/a.mp3" data-title="ZEBRA" data-artist="MORDAX Bastards">…</a></li>
  <li><a href="/media/b.mp3">…</a></li>
</ol>
<script src="textplayer.js"></script>
<script>
  TextPlayer.attach({ links: "ol a[href$='.mp3']" });
</script>
```

Файл можно и встроить прямо в `<script>` на странице. Поэтому в `textplayer.js` не должно
быть строки с закрывающим тегом script, иначе браузер оборвёт скрипт на ней.

Если репозиторий публичный, файл можно брать с jsDelivr:
`https://cdn.jsdelivr.net/gh/<пользователь>/<репозиторий>@<тег>/web/textplayer/textplayer.js`
(указывайте конкретный тег, а не ветку).

Без JavaScript ссылки работают как обычно: открывают файл.
Ctrl-, Cmd- и Shift-клик тоже работают по-прежнему: файл открывается в новой вкладке или окне.

## Данные эпизода

Берутся из `data-*` атрибутов ссылки. Все атрибуты необязательные.

| атрибут        | строка в окне | если нет                     |
|----------------|---------------|------------------------------|
| `data-file`    | File          | имя файла из `href`          |
| `data-title`   | Title         | текст ссылки                 |
| `data-artist`  | Artist        | пусто                        |
| `data-podcast` | Podcast       | пусто                        |
| `data-date`    | Date          | пусто                        |
| `data-size`    | Size (байты)  | пусто                        |
| `data-format`  | Codec         | битрейт, оценённый по размеру и длительности |

`data-format` — готовая строка, например `MPEG-1 Layer III  192 kbps CBR  44.1 kHz  Stereo`.
Браузер не сообщает параметры потока, поэтому их нужно получить заранее на сервере
(в podcast-site это делает `podscan`, модуль `mpeg.rs`).

## Параметры `attach`

| параметр       | по умолчанию            | что задаёт |
|----------------|-------------------------|------------|
| `links`        | `"a[data-tp]"`          | CSS-селектор или массив элементов `<a>` |
| `title`        | `"Browser Player v<версия>"` | заголовок в верхней рамке |
| `lang`         | `""`                    | язык справки по `H`: `en`, `ru` или `uk` (подойдёт и `ua`); пусто — `<html lang>` страницы, иначе английский |
| `item`         | `"li"`                  | ближайший предок ссылки, которому ставится `playingClass` (если такого нет, класс получает сама ссылка) |
| `playingClass` | `"tp-playing"`          | класс текущего трека, чтобы подсветить его в списке |
| `width`        | `70`                    | внутренняя ширина окна в символах |
| `bufferTarget` | `60`                    | сколько секунд запаса впереди точки воспроизведения считать полным буфером `Buf` |
| `spectrum`     | `true`                  | анализатор спектра под строкой прогресса: столбики-«светодиоды» из сегментов `▂▂`, от 50 Гц до 16 кГц (Web Audio) |
| `spectrumRows` | `16`                    | сегментов в столбике (сегмент — примерно треть строки) |
| `spectrumCookie` | `"tp_spectrum"`      | cookie, в которой на год запоминается выбор клавиши `A` (`1` — показан, `0` — спрятан) |
| `spectrumTheme` | `"classic"`            | цветовая тема анализатора, пока посетитель не выбрал свою клавишей `T` (см. ниже) |
| `spectrumThemeCookie` | `"tp_spectrum_theme"` | cookie, в которой на год запоминается выбор клавиши `T` (id темы) |
| `engine`       | `null`                  | `{ wasm, worklet }`: адреса `audiocore.wasm` и `worklet.js` — движок на WebAssembly (см. ниже) |
| `gapless`      | `true`                  | с движком: следующий трек начинается сразу за текущим, без паузы |

`attach` возвращает `{ open(index), close(), audio }` или `null`, если ссылок нет.
`TextPlayer.themes` — список тем анализатора в виде `{ id, name }`.

### Темы анализатора

`T` — следующая тема, `Shift+T` — предыдущая; на секунду в разделителе под анализатором
появляется название новой (`─ Fire ─`). Каждая красит сегменты по высоте, снизу вверх:

| id | название | цвета |
|---|---|---|
| `classic`   | Classic   | зелёная, жёлтая, красная полосы, как у светодиодных индикаторов (CSS-переменные ниже) |
| `fire`      | Fire      | тёмно-красный, красный, оранжевый, жёлтый |
| `ice`       | Ice       | тёмно-синий, синий, голубой, бирюзовый |
| `rainbow`   | Rainbow   | фиолетовый, синий, зелёный, жёлтый, красный |
| `matrix`    | Matrix    | от тёмно- до ярко-зелёного |
| `amber`     | Amber     | от коричневого до янтарного, как янтарный монитор |
| `synthwave` | Synthwave | фиолетовый, пурпурный, розовый, бирюзовый |

## Движок на WebAssembly

С параметром `engine` MP3 играет через Web Audio, а не через элемент `<audio>`. Страница
сама скачивает файл (примерно на две минуты вперёд), а AudioWorklet (`worklet.js`)
декодирует его движком [audiocore](../../audiocore) — Rust, собранный в WebAssembly,
побитово совпадающий с minimp3. Что это даёт:

- **бесшовное воспроизведение** (`gapless: true`): задержка кодировщика и добивка
  отрезаются (по LAME-тегу), следующий трек скачивается, как только докачан текущий, и
  начинается со следующего же сэмпла; при `gapless: false` — после окончания текущего;
- перемотка — новый запрос с `Range` от байта нужного времени (постоянный битрейт), конец
  трека и после неё обрезается точно.

Пока играет движок, в поле `Decoder:` написано `audiocore`; с `<audio>` — имя браузера.

Движок включается, только если ссылки ведут на тот же сайт и заканчиваются на `.mp3`, а
браузер умеет AudioWorklet и WebAssembly; если он не загрузился, плеер переходит на
`<audio>` и продолжает тот же трек. Оба файла отдавайте под именем, которое меняется
вместе с содержимым (sitegen: `player/audiocore.<хеш>.wasm`), с долгим кешем; в
Content-Security-Policy нужны `script-src 'self' 'wasm-unsafe-eval'` и `connect-src 'self'`.

## Управление

- Клавиши: пробел — следующий трек, `P` — предыдущий, `<` `>` или `←` `→` — перемотка
  на 10 секунд, `↑` `↓` — на минуту, `S` — пауза, `+` `-` — громкость, `A` — показать или спрятать анализатор спектра (окно меняет размер,
  выбор запоминается в cookie), `T` / `Shift+T` — следующая / предыдущая тема анализатора
  (тоже запоминается в cookie; спрятанный анализатор при этом показывается), `H` — подробная
  справка вместо строки подсказок (все клавиши и мышь, на языке страницы), `Esc` или
  Backspace — закрыть окно (при открытой справке — закрыть справку). Клавиши
  определяются по `e.code`, поэтому работают в любой раскладке.
- Мышь: клик и перетаскивание по полосам прогресса и громкости, клик мимо окна закрывает его.
  Подсказка по клавишам — просто текст, мышь на неё не реагирует.

**Перемотка требует, чтобы сервер поддерживал Range-запросы (ответ 206).** Без этого браузер
не может перейти к нужному месту файла.

## Оформление

Цвета и шрифт меняются CSS-переменными на `:root` или `.tp-overlay`:

| переменная        | по умолчанию | |
|-------------------|--------------|-|
| `--tp-bg`         | `#aaa`       | фон окна |
| `--tp-label`      | `#00a`       | подписи и полосы |
| `--tp-value`      | `#ff5`       | значения |
| `--tp-frame`      | `#fff`       | рамки |
| `--tp-title-bg`, `--tp-title` | `#fff`, `#555` | заголовок |
| `--tp-help`       | `#000`       | подсказка по клавишам |
| `--tp-backdrop`   | `rgb(0 0 0 / .55)` | затемнение страницы |
| `--tp-font`       | `"DejaVu Sans Mono", Menlo, Consolas, "Liberation Mono", monospace` | шрифт |
| `--tp-font-size`  | `min(16px, calc((100vw - 2rem) / 44))` | размер шрифта: окно помещается на экран телефона |
| `--tp-z`          | `1000`       | z-index |
| `--tp-spec-low`, `--tp-spec-mid`, `--tp-spec-high` | `#1a1`, `#cc0`, `#d22` | сегменты анализатора в теме Classic: низ, середина, верх |

Как устроен анализатор: столько полос, сколько помещается в окно от края до края (23 при ширине
по умолчанию), равномерно в логарифмической шкале от 50 Гц до 16 кГц;
полоса показывает свою среднюю мощность (а не самый громкий отсчёт) с наклоном +4,5 дБ на
октаву вокруг 1 кГц — в музыке энергия к высоким падает, и без наклона правая половина всегда
низкая. Столбики поднимаются сразу и опадают с постоянной скоростью в секундах (одинаково на
экранах 60 и 120 Гц); над каждым столбиком 0,8 с висит пик, потом медленно опускается. Шкала
(−80…−36 дБ после наклона) измерена на подкастах этого сайта: обычный уровень — около
половины столбика, громкие места доходят до жёлтых и красных сегментов.

Анализатор включается, только если все ссылки ведут на тот же сайт, что и страница: элемент,
подключённый к Web Audio, воспроизводит звук с чужого домена (без CORS) как тишину. Иначе
плеер работает как раньше, просто без столбиков.

Нужен моноширинный шрифт с символами рамок (`╔═║`) и блоков (`█░`), иначе рамки разъедутся.

## Версии

[Семантическое версионирование](https://semver.org/lang/ru/): MAJOR — несовместимые
изменения параметров, API или CSS-переменных, MINOR — новые возможности, PATCH —
исправления. Версия — `VERSION` в начале `textplayer.js`, единственная её копия: её
показывают заголовок по умолчанию и `TextPlayer.version`. Любая правка файла
поднимает версию и добавляет запись в [CHANGELOG.md](CHANGELOG.md); CI не пропустит pull
request, который меняет файл без новой версии или чей changelog начинается не с неё.
